# Read anything

把「登录墙后面的内容」变成 agent 能直接读的工具。三个工具：

| 工具 | 作用 |
|---|---|
| `list_site` | 在指定站点搜索，返回标题/作者/链接/摘要 |
| `read_url` | 读单条详情正文（可选评论） |
| `suggest` | 把口语问题改写成各站查询词 |

## 站点

小红书、知乎、微博、CSDN、贴吧、Reddit、YouTube 开箱可用；
Handshake 需改成你学校的子域，X / LinkedIn 需登录。

## 核心行为：失败时说清楚

被墙、未登录、选择器失效时，工具返回 `ok:false` 并附三层替代路径：

1. **找镜像 / 免登录入口** —— 同一份内容，换条路能通
2. **换站** —— 换个社区问同一个问题
3. **找转载** —— 用标题原文搜

模型照这个顺序执行，不要在原站重试。

## 限制

- 依赖本机安装的浏览器与 Python 环境，路径写在 `cordis.patch.yml` 里。
- 小红书/知乎需要先登录一次（`login.py`）。
- 各站选择器会随改版失效，届时 `list_site` 会报错而不是返回空。
